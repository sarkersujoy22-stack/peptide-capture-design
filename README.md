# Computational Design of Bacterial-Capture Peptides

## Project Overview
This project explores peptide candidates for capturing
Gram-positive and Gram-negative bacteria.

## Objectives
- Analyze peptide physicochemical properties
- Evaluate net charge and hydrophobicity
- Investigate predicted peptide structures
- Prioritize candidates for experimental validation

## Tools
- Python
- HeliQuest
- RCSB Protein Data Bank
- UCSF ChimeraX

## Workflow
1. Collect candidate peptide sequences
2. Analyze physicochemical properties
3. Explore available structural information
4. Compare and prioritize candidates
5. Document results and limitations

## Project Status
In progress

## Important Note
Computational predictions do not establish bacterial
binding, capture efficiency, or non-bactericidal activity.
Experimental validation is required.
